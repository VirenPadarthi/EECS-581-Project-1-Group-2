# EECS-581-Project-1
Project oriented on minesweeper game development from EECS 581 Fall 2026
* Used pygame to develop the minesweeper project

# Requirements
Pygame [ (bash) pip install pygame ]
Python 3.13

# Features
  10 x 10 Minesweeper board
  Rows : 1 -10, Columns : A - J
  Win or lose concept
  R key to restart the game
  Random bomb placements
  Click left to reveal tiles
  Right click to add or remove flags
  First clicked tile is a confirmed safe tile.

# python minesweeper.py to run
